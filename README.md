Company site for **Haven Command LLC** — a custom software development and digital product studio.

Two sides of the same shop:

1. **Custom software for clients** — web apps, business software, AI-powered apps, automation, APIs, portals, internal tools, SaaS, games, and specialized software.
2. **Own products** as a living portfolio.

Live products (verified): D4Chess, ScriptForge AI, AutoSocial, TheraScribe, Emoji Isle.  
In development (not live): TrustLoopAI, Cognition.  
Experiments stay labeled as experiments.

The [insights](blog/) archive is a dated record of what those products had to survive — one bottleneck per note. `/blog/` URLs are unchanged.

Static site. Deploys to GitHub Pages on push to `main`.
